# 跨境吴老师 AMAZON 广告搜索词优化 Skill

使用当前平台已授权的领星 MCP，读取帐号下**全部广告站点和店铺**的四个固定日期窗口商品推广客户搜索词报告，交付可按日期、广告组合及单个客户搜索词切换的离线 HTML“跨境吴老师AMAZON广告搜索词优化看板”。

## 运行前准备

在自己的执行平台配置并授权领星 MCP，确保可以调用广告授权店铺查询 `ad_auth_shops` 与广告搜索词报告 `ad_campaign_search_term_report`。Skill 先验证工具、连接和广告授权；广告组合名称还须由报告直接提供或经当前领星身份工具可靠映射。失败时提示具体缺失能力或重新授权，不索取密钥，也不使用本机历史表格补位。

无需先指定店铺、站点或日期；Skill 会查询本次授权清单的全部 Profile，以及 `7天`、`14天`、`本月`、`上月` 四个窗口，默认打开上月。可指定其中一个作为初始窗口。含当天的窗口可能尚未完成归因。

## 首次安装

本仓库为公开仓库。将以下整段指令发送给 Codex：

```text
请从 https://github.com/defway888-design/kuajing-wulaoshi-amazon-search-term-optimization 安装跨境吴老师 AMAZON 广告搜索词优化 Skill。
```

安装后按 Codex 的提示重新加载 Skill；若客户端要求重启，则关闭并重新打开 Codex。

## 启动

```text
使用 $kuajing-wulaoshi-amazon-search-term-optimization 生成跨境吴老师AMAZON广告搜索词优化看板。
初始统计日期：上月
```

## 看板内容

- 八项筛选：统计日期、站点、国家、店铺、广告组合名称、广告活动名称、广告组名称、客户搜索词。站点代码和国家名称联动；关键词按当前条件下的点击量降序单选，每次只展示当前词的一组图表与建议。
- 切换筛选后立即重算可选的全部客户搜索词、活动花费、点击加权转化率和人工复核建议。没有 Top10 限制；同名实体按内部身份分别计算，内部 ID 不展示。
- 多站点视图可合计点击量；不同币种花费按站点分别展示，不出混币合计。跨活动倾斜只在同一店铺站点的同词活动之间判断。
- 顶部显示本包内嵌的跨境吴老师 Logo，高度 60 像素；没有“数据说明”板块。最终**必须**交付单文件离线 HTML，支持时可另附对话内交互预览；文件本身不依赖 CDN、在线图片或本机其他文件。

本 Skill 只用客户搜索词报告，不把投放关键词、商品／ASIN 报告当作替代来源，不自动修改广告。

## 失败边界

任一“授权 Profile × 日期窗口”读取失败、分页不完整、归属冲突，或广告组合名称无法可靠映射时，停止正式看板并说明受影响范围。不会把局部数据标为全帐号。数据质量或 CVR 单位无法确认时按 [数据契约](references/data_contract.md) 标注／停止相应分析，绝不编造。

公开 Skill 包不包含店铺、Profile ID、客户搜索词、广告活动、报告、HTML 结果或凭据。运行生成的离线 HTML 应保存到当前运行者有权限的输出目录，不能放入公开 Skill 仓库。
