# 跨境吴老师 AMAZON 广告搜索词优化 Skill

使用当前平台已授权的领星 MCP，先从授权店铺清单生成**统计日期、国家、店铺三项交互筛选页**；点击“运行并生成看板”后，读取所选日期、国家和店铺对应的商品推广客户搜索词报告，再用固定母版交付单文件离线 HTML“跨境吴老师AMAZON广告搜索词优化看板”。

## 运行前准备

在自己的执行平台配置并授权领星 MCP，确保可以调用广告授权店铺查询 `ad_auth_shops` 与广告搜索词报告 `ad_campaign_search_term_report`。Skill 先验证工具、连接和广告授权；广告组合名称还须由报告直接提供或经当前领星身份工具可靠映射。失败时提示具体缺失能力或重新授权，不索取密钥，也不使用本机历史表格补位。

运行环境还需能执行 Python 3.8 或更新版本，能在本机回环地址启动本包 `scripts/selection_bridge.py` 并保持 Agent 等待按钮提交，且保持母版、Logo 和渲染器完整。正式 HTML 只能由固定渲染器生成并通过 `--check` 校验；不能依据文字说明自行另写看板。经核验全部活动未加入广告组合时，无需 `ad_portfolios`；存在已加入组合的活动则需要可靠的组合名称来源。

无需在启动时先填写店铺、站点或日期。第一阶段只查询授权清单并展示 `7天`、`14天`、`本月`、`上月` 与授权店铺；点击运行后才查所选范围的报告。含当天的窗口可能尚未完成归因。第一阶段是本地服务承载的交互页，最终看板才是可独立打开的离线 HTML。


安装后按 Codex 的提示重新加载 Skill；若客户端要求重启，则关闭并重新打开 Codex。

## 启动

```text

在第一页选择统计日期、国家和店铺，然后点击“运行并生成看板”。
```

## 看板内容

- 第一阶段选择统计日期、国家、店铺，点击“运行并生成看板”。页面通过本机服务把选择及内部派生的站点代码交给当前 Agent，无需下载、上传或粘贴文件。第一阶段不展示报告指标。
- 第二阶段只读取所选范围的完整报告，生成正式离线看板。页面自动跳转到结果；对话中也提供可保存的 HTML 文件链接。若按钮未真正提交，不会查询报告或生成正式页。
- 七项筛选：统计日期、国家、店铺、广告组合名称、广告活动名称、广告组名称、客户搜索词。国家选项内部对应站点代码；关键词按当前条件下的点击量降序单选，每次只展示当前词的一组图表与建议。
- 在**本次已获取的范围内**切换筛选后立即重算可选的全部客户搜索词、活动花费、点击加权转化率和人工复核建议。更换日期或扩大国家／店铺范围需重新运行第一阶段。没有 Top10 限制；同名实体按内部身份分别计算，内部 ID 不展示。
- 多站点视图可合计点击量；不同币种花费按站点分别展示，不出混币合计。跨活动倾斜只在同一店铺站点的同词活动之间判断。
- 顶部显示本包内嵌的跨境吴老师 Logo，高度 60 像素；没有“数据说明”板块。最终**必须**交付单文件离线 HTML，支持时可另附对话内交互预览；文件本身不依赖 CDN、在线图片或本机其他文件。
- 页面结构、CSS、组件、图表和交互由同一母版锁定。宽屏图表按可用宽度铺开，活动过多时可横向滚动；真实数据文字、图表数量与数值会变化。相同浏览器、视口、缩放和字体条件下保持同版式。不同系统与浏览器的字体栅格可能不同，无法保证逐像素完全一样。

本 Skill 只用客户搜索词报告，不把投放关键词、商品／ASIN 报告当作替代来源，不自动修改广告。

## 失败边界

本地交互服务不可用时，明确说明无法由按钮启动第二阶段。任一选中 Profile 的报告读取失败、分页不完整、归属冲突，或广告组合名称无法可靠映射时，不生成正式看板，并在页面显示事实原因。数据质量或 CVR 单位无法确认时按 [数据契约](references/data_contract.md) 停止相应分析，绝不编造。

公开 Skill 包不包含店铺、Profile ID、客户搜索词、广告活动、报告、HTML 结果或凭据。运行生成的离线 HTML 应保存到当前运行者有权限的输出目录，不能放入公开 Skill 仓库。
