# 跨境吴老师 AMAZON 广告搜索词优化 Skill

使用运行者已配置的领星 MCP，分析 Amazon 商品推广客户搜索词点击量前十及其在不同广告活动中的转化表现，生成“跨境吴老师AMAZON广告搜索词优化看板”。

## 适用场景

- 查看同一客户搜索词在不同 SP 广告活动中的花费与点击加权转化率。
- 识别主推、保留测试、谨慎限流及活动级暂停／否定候选。
- 数据不足或只有一个活动时，明确展示限制，不编造跨活动结论。

不用于 DSP、AMC、历史 Excel、订单或销售额分析，也不自动更改广告。

## 运行前准备

在自己的执行平台配置并授权领星 MCP，确保可以调用广告授权店铺查询和广告活动搜索词报告。Skill 启动后会先检查 MCP 工具、连接及广告店铺授权；未配置成功时先提示完成配置。无需在聊天或仓库中提供密钥。

配置检查通过后，提供店铺名称、站点，以及“7天、14天、本月、上月”之一。

安装后按 Codex 的提示重新加载 Skill；若当前客户端要求重启，则关闭并重新打开 Codex。

## 执行结果与失败边界

成功时交付可交互的看板，最多展示实际存在的前 10 个客户搜索词。若当前平台不能在对话内渲染交互画布，可额外交付离线 HTML，但会明确说明画布要求未满足。

领星 MCP 缺失、鉴权或广告店铺授权失败、报告为空／分页不完整、CVR 单位无法确认时停止，不使用本地报表或样例数据补位。

## 使用边界与安全

公开仓库不包含店铺、Profile ID、客户搜索词、广告活动、报告或凭据。页面不展示内部标识。所有优化建议供人工复核，不会直接修改广告。
