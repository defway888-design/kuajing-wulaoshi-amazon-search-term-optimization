# 所选范围商品推广客户搜索词数据契约

## 覆盖范围与身份

- 绩效数据的唯一来源是本次运行的领星 `ad_campaign_search_term_report`；`ad_auth_shops` 提供第一阶段授权身份。为广告组合名称筛选，可从报告行直接取得经核验的组合身份／名称，或只用领星 `ad_campaign_report`、`ad_portfolios` 的身份映射字段；补充报告的绩效指标一律不用。授权响应若显示截断而当前工具不能翻页则停止。第一阶段在当前对话只提供日期及授权国家选项；第二阶段查询用户提交的窗口及所选国家的**全部授权 Profile**，覆盖分母为该窗口 × 所选国家全部授权 Profile。选择“全部国家”则覆盖本次授权清单全部 Profile。
- `profile_id` 用于查询和归属校验，`campaign_id`、`ad_group_id` 用于区分同名实体。可在处理内存中使用，但输出 HTML 仅保留运行时生成的不含源 ID 的临时序号。不得把真实 ID、密钥或多余原始字段嵌入页面。
- 渲染输入必须同时包含本次完整 `authorizedProfiles` 与所选国家的 `profiles`。渲染器按授权清单计算应命中的 Profile 集合并要求精确相等；零记录 Profile 仍进入 `profiles` 和 `coverage`。`selectedScope` 只含日期、站点代码和国家，不含店铺选择。授权清单只留在本次运行输入，不进入最终 HTML。
- 各工具参数类型以当次 Schema 为准。授权响应的 Profile ID 若为数字字符串，而辅助工具要求整数，仅在可无损解析为安全整数时转换；否则使用同一授权记录中经 Schema 允许的其他身份键，仍无法调用则停止。先核对平台包装层和业务 `success`／`code`，不能把错误对象或未识别的响应容器误判为空报告。
- 店铺名取授权记录的 `alias`，站点代码取 `country`；国家显示名来自确定的代码映射。未支持的代码原样显示“XX（国家名称未核实）”，不猜测名称。若报告行给出 `profile_id` 或 `country` 且与本次单 Profile 请求冲突，停止并说明归属冲突；缺少报告行 Profile ID 时可由该单 Profile 请求上下文确定。
- 报告只取 `sponsored_type=['sp']`。绩效分析字段仅为 `query`、`campaign_name`、`ad_group_name`、`clicks`、`spends`、`cvr`，加授权店铺和站点维度；`portfolio_id`／经核验的组合名称只用于筛选身份。广告组名称必须由报告真实字段提供；缺失时列数据问题，不虚构“未命名广告组”。当前工具若没有输出 Schema，先核验实际记录键、类型、单位和响应容器，不把历史样本字段当作接口保证。

## 广告组合身份与名称

1. 优先采用搜索词报告行中经当前响应证实的 `portfolio_id` 和组合名称。仅有组合名称而不能区分同名组合时，可按名称筛选命中全部同名实体，但不得错误合并实体统计。
2. 若报告行只含 `portfolio_id`，按“Profile＋portfolio_id”与领星 `ad_portfolios` 的 `profile_id`、`portfolio_id`、`name` 唯一映射。若报告行只有 `campaign_id`，先从同一 Profile 的 `ad_campaign_report` 建立“Profile＋campaign_id → portfolio_id”关系，再查组合名称。辅助工具必须读取全分页并核验 ID 类型、归属与唯一性，不使用它们的花费、点击或转化指标。
3. 仅当来源明确证明活动未加入组合，才标为“未加入广告组合”。这种行无需 `ad_portfolios`；全部活动均被证实未加入组合时，缺少 `ad_portfolios` 也可继续。字段缺失、活动关联缺失、同 ID 异名、跨 Profile 冲突或非空组合 ID 映射不到名称时停止正式看板生成。不得拿活动名、广告组名、店铺名或模拟数据代替组合名。若当前平台无法验证上述任何一种链路，明确说明广告组合关联能力不足。

## 分页、总计行与零记录

所选窗口分别按命中 Profile 从第 1 页连续读取。若 `recordsFiltered` 存在，先识别它是明细数还是包含总计行的记录数，再核对累计数据；口径不明时继续到无有效明细页，不能据猜测提前停。每页可能附带总计行。只有 `query`、`campaign_name`、`profile_id`、`campaign_id`、`ad_group_name`、`ad_group_id` 同时为空，且仅有汇总指标语义时才排除。不能把总计行标为普通词或活动。

普通明细不按内容或行 ID 去重；重复页检测只识别整页重复、分页停滞等故障，不能删除看似相同的合法记录。若计数冲突、页面循环、接口错误或无法确定是否读取全部明细，停止正式看板生成。一个“所选窗口＋Profile”的可靠空报告记为零记录组合；所选范围全部为空则不生成看板，不转查其他窗口。

## 清洗、排序与转化率

1. 搜索词去首尾空格；英文比较忽略大小写，展示首次有效原文。不能按相似度合并，也不能用投放关键词替代 `query`。非总计行的 `query` 为空，或 `clicks` 缺失、非有限数、负数时无法可靠全量排序，应停止并列受影响记录数。零点击明细保留。
2. `spends` 须为有限非负数；无效值不得当 0。保留受影响搜索词，但其所在实体花费标为“不完整”，不能做花费比较或执行建议。`cvr` 缺失或越界也不当 0；受影响实体转化率标为“不完整”。花费、点击量和转化率允许数字或可无歧义解析的数字字符串，不接受空串、破折号和非有限值。
3. 先核实 `cvr` 单位。优先依据实际工具说明或元数据；接口若为百分数值，25 表示 25%，合法区间为 0–100，渲染输入保持 25；若明确为 0–1 比例，合法区间为 0–1，渲染前乘 100。无说明时，当前同一接口报告中存在有效 `cvr>1` 且不超过 100 可判为百分数值；全部为 0 可展示 0%。只有 0–1 之间正值而无可靠说明时，停止正式看板生成并提示“CVR 单位待核对”；不能向固定模板输入不明单位。不能凭店铺或站点自行设不同单位。
4. 对当前日期窗口和其他筛选后的行按规范化 `query` 聚合 `Σclicks`，点击量降序、同分按规范化搜索词升序。固定模板的原生单选关键词下拉框包含全部词，不得只装载前十或另换自制搜索控件。每次筛选后必须重算选项与排名，不能复用全局聚合值。零点击词排在有点击词之后；默认选第一词，每次只渲染一个选中词的明细看板。
5. 搜索词的点击加权转化率 = `Σ(clicks_i × cvr_i) / Σclicks_i`；仅当所有正点击行 CVR 完整且单位一致时显示。分母为 0 显示“不适用”。同样算法用于活动／广告组实体。不得把百分数均值或活动 CVR 简单平均。
6. 实体粒度为授权 Profile＋活动 ID＋广告组 ID；活动图按 Profile＋活动 ID 聚合，同一活动下多个广告组求和。广告组合按 Profile＋组合 ID 区分，同名筛选命中当前范围内全部同名组合。活动名缺失的行仍进入搜索词点击排序，但活动图标记“活动信息不完整”，不作活动优化建议。ID 缺失时可按名称列示，但若当前 Profile 内存在同名冲突，不合并为确定实体，也不对其作倾斜建议。活动／广告组名称筛选均按名称匹配；各项筛选为行级交集。
7. 花费只在**可确定同一币种**的行间相加。国家／站点对应币种必须有可靠来源或明确映射；未知时用“站点货币”标注原数，不出跨站花费总额。所选范围若含多个币种，选中词的图表按 Profile／币种分面，绝不能把不同币种画在同一金额轴。点击量和可比较的 CVR 可跨站聚合，但活动建议只能同 Profile 内比较。

## 七项筛选与单关键词切换

- 顺序固定：统计日期、国家、店铺、广告组合名称、广告活动名称、广告组名称、客户搜索词。第一阶段只在当前对话收集**日期、国家**，来自固定日期定义和授权清单；用户提交后才读取所选国家全部店铺的搜索词报告。正式看板显示七项，日期与国家只可在本次已读取范围内切换，店铺可在本次已获取的全部店铺间切换；后四项由完整报告生成。关键词始终单选，按当前交集点击量降序。
- 国家卡片以站点代码（US、CA 等）为内部值、国家名称为显示值；不存在独立的站点筛选卡片。国家名称与站点代码必须唯一对应，选择国家即确定站点范围，清空表示全部国家。店铺选项是授权 `alias`；跨站同名店铺的标签添加站点代码，内部精确到授权 Profile。
- 选项从当前窗口已校验数据和授权／组合映射生成，按上游筛选收窄；更改上游时清空失效的下游值，不保留不可达选择。组合／活动／广告组选项按名称筛选，同名选项命中全部同名实体，图表仍按无源信息临时键分别统计。无有效广告组名的行留在搜索词聚合中并显示“广告组信息不完整”，不得混入真实广告组选项。
- 第一阶段通过当前对话的原生选择提交或用户明确回复只取得日期、国家；Agent 派生站点代码并校验国家／站点唯一映射及命中 Profile 非空。即使用户额外写了店铺，也不按店铺收窄本次查询，并向用户说明将覆盖所选国家全部授权店铺。用户未提交完整有效的两项条件前不得查询报告；不生成筛选页面、运行按钮、本地服务或选择文件。
- 正式页以已确认的选择为初始视图，保留所选窗口和 Profile 的完整数据。后续每次变更在本地重算关键词排序、当前词图表、提示框和建议，不再请求 MCP。原选词仍存在则保留，否则切到新范围第一词；新结果为空时禁用关键词选择并清空图与建议。允许重置本次范围内的筛选。

## 优化建议

建议粒度为同一 Profile、同一客户搜索词下的活动；如用户选了广告组，基于筛选后真实剩余行重新评估，明确标注“当前筛选范围”。跨店铺或跨站点无对照结论。默认有效样本门槛：每活动该词至少 20 点击；只是操作阈值，不代表统计显著。建议写明点击量、同币种花费、点击加权转化率和原因，供人工复核，不调用广告写接口。

- **主推并倾斜候选**：至少两个身份明确、数据完整且各达 20 点击的活动；某活动正 CVR 严格高于其他合格活动。并列或仅一个合格活动则不设主推。
- **保留测试**：有转化但点击不足 20，或零转化且点击不足 20；仅一个活动时只作单活动观察。
- **降低出价／限流候选**：在同 Profile、同词、至少两个合格活动中，某活动 CVR 低于主推候选，且其自身至少 20 点击、数据完整；不推断具体出价幅度。
- **暂停／活动级否定候选**：零转化且点击达 20、数据完整、报告更新和归因成熟已核实后，才可另行人工判定。当前固定模板没有归因成熟度输入，正式看板只列“数据待核对／暂缓执行”，不自动给出暂停或否定候选。若同词在其他活动有转化，绝不建议全局否定。
- 数据或身份不完整、CVR 单位不明、零点击时仅展示待核对／样本不足，不给倾斜、限流或暂停结论。花费高低单独不能证明转化优劣。
