# 全帐号商品推广客户搜索词数据契约

## 覆盖范围与身份

- 唯一来源是本次运行的领星 `ad_auth_shops` 与 `ad_campaign_search_term_report`。授权接口若分页须取完全部页；查询全部授权广告 Profile，各 Profile 分别完整分页；授权清单是覆盖分母。
- `profile_id` 用于查询和归属校验，`campaign_id`、`ad_group_id` 用于区分同名实体。可在处理内存中使用，但输出 HTML 仅保留运行时生成的不含源 ID 的临时序号。不得把真实 ID、密钥或多余原始字段嵌入页面。
- 店铺名取授权记录的 `alias`，站点代码取 `country`；国家显示名来自确定的代码映射。未支持的代码原样显示“XX（国家名称未核实）”，不猜测名称。若报告行给出 `profile_id` 或 `country` 且与本次单 Profile 请求冲突，停止并说明归属冲突；缺少报告行 Profile ID 时可由该单 Profile 请求上下文确定。
- 报告只取 `sponsored_type=['sp']`。分析字段仅为 `query`、`campaign_name`、`ad_group_name`、`clicks`、`spends`、`cvr`，加授权店铺和站点维度。广告组名称必须由报告真实字段提供；缺失时列数据问题，不虚构“未命名广告组”。

## 分页、总计行与零记录

逐 Profile 从第 1 页连续读取。若 `recordsFiltered` 存在，先识别它是明细数还是包含总计行的记录数，再核对累计数据；口径不明时继续到无有效明细页，不能据猜测提前停。每页可能附带总计行。只有 `query`、`campaign_name`、`profile_id`、`campaign_id`、`ad_group_name`、`ad_group_id` 同时为空，且仅有汇总指标语义时才排除。不能把总计行标为普通词或活动。

普通明细不按内容或行 ID 去重；重复页检测只识别整页重复、分页停滞等故障，不能删除看似相同的合法记录。若计数冲突、页面循环、接口错误或无法确定是否读取全部明细，停止正式看板。一个 Profile 的可靠空报告记为零记录 Profile；所有 Profile 均空则不生成看板。

## 清洗、排序与转化率

1. 搜索词去首尾空格；英文比较忽略大小写，展示首次有效原文。不能按相似度合并，也不能用投放关键词替代 `query`。非总计行的 `query` 为空，或 `clicks` 缺失、非有限数、负数时无法可靠全量排序，应停止并列受影响记录数。零点击明细保留。
2. `spends` 须为有限非负数；无效值不得当 0。保留受影响搜索词，但其所在实体花费标为“不完整”，不能做花费比较或执行建议。`cvr` 缺失或越界也不当 0；受影响实体转化率标为“不完整”。报告金额和点击量允许数字或可无歧义解析的数字字符串，不接受空串、破折号和非有限值。
3. 先核实 `cvr` 单位。优先依据实际工具说明或元数据；接口若为百分数值，25 表示 25%，合法区间为 0–100，计算转为 0.25；若明确为 0–1 比例，合法区间为 0–1，直接使用。无说明时，当前同一接口报告中存在有效 `cvr>1` 且不超过 100 可判为百分数值；全部为 0 可展示 0%；只有 0–1 之间正值而无可靠说明时，停止转化率比较及建议，并在看板将 CVR 显示“单位待核对”。不能凭店铺或站点自行设不同单位。
4. 对当前筛选后的行按规范化 `query` 聚合 `Σclicks`，点击量降序、同分按规范化搜索词升序。展示全部搜索词，列表可搜索／滚动，不得只显示前十。未筛选时用全帐号行集合；每次筛选后必须重算，不能复用全局聚合值。零点击词排在有点击词之后。
5. 搜索词的点击加权转化率 = `Σ(clicks_i × cvr_i) / Σclicks_i`；仅当所有正点击行 CVR 完整且单位一致时显示。分母为 0 显示“不适用”。同样算法用于活动／广告组实体。不得把百分数均值或活动 CVR 简单平均。
6. 实体粒度为授权 Profile＋活动 ID＋广告组 ID；活动图按 Profile＋活动 ID 聚合，同一活动下多个广告组求和。活动名缺失的行仍进入搜索词点击排序，但活动图标记“活动信息不完整”，不作活动优化建议。ID 缺失时可按名称列示，但若当前 Profile 内存在同名冲突，不合并为确定实体，也不对其作倾斜建议。广告组名称筛选只按名称匹配；活动／广告组筛选可同时生效，结果为行级交集。
7. 花费只在**可确定同一币种**的行间相加。国家／站点对应币种必须有可靠来源或明确映射；未知时用“站点货币”标注原数，不出跨站花费总额。全帐号视图若含多个币种，搜索词列表按站点／币种分别列花费，图表按币种分面或要求先选站点，绝不能把不同币种画在同一金额轴。点击量和可比较的 CVR 可跨站聚合，但活动建议只能同 Profile 内比较。

## 五张筛选卡片

- 顺序固定：站点、国家、店铺、广告活动名称、广告组名称。初始均为“全部”。站点为代码（US、CA 等），国家为其对应显示名；两卡片由同一 `country` 维度派生，选择一方时另一方同步，清空时也同步。
- 选项从当前已校验数据和授权映射生成，按前序筛选收窄；更改上游筛选时清空失效的下游值，不保留不可达选择。空结果明确显示 0 条，不沿用之前结果。允许重置全部。
- 店铺选项是授权 `alias`；跨站同名店铺的显示标签添加站点代码，筛选仍精确到对应授权 Profile。活动／广告组选项按名称筛选；同名名称命中筛选范围内所有同名实体，图表用内部实体身份分开统计。无有效广告组名的行须留在搜索词结果并显示“广告组信息不完整”，但不得混入某个真实广告组选项。
- 每次变更立即在本地重算搜索词排序、总数、明细图、提示框及建议；不再请求 MCP。搜索词当前选择在新结果中不存在时，选新结果第一项；新结果为空时清空明细和建议。

## 优化建议

建议粒度为同一 Profile、同一客户搜索词下的活动；如用户选了广告组，基于筛选后真实剩余行重新评估，明确标注“当前筛选范围”。跨店铺或跨站点无对照结论。默认有效样本门槛：每活动该词至少 20 点击；只是操作阈值，不代表统计显著。建议写明点击量、同币种花费、点击加权转化率和原因，供人工复核，不调用广告写接口。

- **主推并倾斜候选**：至少两个身份明确、数据完整且各达 20 点击的活动；某活动正 CVR 严格高于其他合格活动。并列或仅一个合格活动则不设主推。
- **保留测试**：有转化但点击不足 20，或零转化且点击不足 20；仅一个活动时只作单活动观察。
- **降低出价／限流候选**：在同 Profile、同词、至少两个合格活动中，某活动 CVR 低于主推候选，且其自身至少 20 点击、数据完整；不推断具体出价幅度。
- **暂停／活动级否定候选**：零转化且点击达 20、数据完整、报告更新和归因成熟已核实。未核实时仅列“数据待核对／暂缓执行”。若同词在其他活动有转化，绝不建议全局否定。
- 数据或身份不完整、CVR 单位不明、零点击时仅展示待核对／样本不足，不给倾斜、限流或暂停结论。花费高低单独不能证明转化优劣。
