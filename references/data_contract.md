# 领星商品推广搜索词数据口径

## 输入与来源

- 唯一来源：当前执行环境已授权的领星广告店铺和搜索词报告能力。
- 店铺匹配：`alias` 去首尾空格、大小写不敏感；`country` 用站点代码规范化。不可用模糊包含匹配代替唯一匹配。
- 仅分析 `sponsored_type=['sp']` 与所选自然日范围内的数据。
- 页面业务指标字段：`query`、`campaign_name`、`clicks`、`spends`、`cvr`。查询所需 `profile_id` 及报告中的 `campaign_id` 仅作为内部身份字段。

## 分页与总计行

从第 1 页连续读取。若 `recordsFiltered` 存在，先核对它表示明细数还是包含总计行的原始记录数，再与累计页数和明细数验证；不能确认其口径时继续翻页至无有效明细，不按猜测提前停止。若无计数字段，以首个无有效明细页终止。监测重复页响应以发现分页故障；该检查不构成行去重。所有非总计的返回明细都参与聚合。

只有 `query`、`campaign_name`、`profile_id`、`campaign_id` 同时为空，且该记录只有汇总指标语义时，才排除为总计行。其他缺字段记录列入数据质量问题，不能改名成“未命名广告活动”后参与建议。

## 清洗与聚合

1. 搜索词去首尾空白；英文比较忽略大小写，展示保留首次有效原文。不可把不同客户搜索词按相似度合并。
2. 每条非总计明细都要纳入数据完整性核对。`query` 为空，或 `clicks` 缺失、非有限数、负数时，无法可靠计算全量 Top10，应停止生成看板并说明受影响记录数，不可直接丢弃该行。`spends` 必须是有限的非负数；缺失时标记花费不完整，不按 0 计算。`cvr` 必须是有限且在其已确认单位范围内的数；缺失时标记转化率不完整，不按 0 计算。
3. 先按搜索词求 `Σclicks`，按点击量降序取最多 10 项；相同点击量时按规范化搜索词升序稳定排序。少于 10 项如实展示。
4. 每个搜索词下用 `campaign_id` 区分同名活动；若 ID 不可用，则按活动名称汇总，并标注同名身份不确定，不作跨活动倾斜结论。内部 ID 不显示。
5. 活动花费 = 同一搜索词与活动所有有效花费行的 `Σspends`。若其中任一行花费无效，花费标记不完整。
6. 先确认当前接口 `cvr` 的单位，优先使用该平台工具说明。若接口返回百分数值，`25.00` 表示 25%，计算时转为 `0.25`；若接口明确为 0–1 比例，直接使用。在未写明单位的同一批报告中，出现有效 `cvr>1` 可判定这一批采用百分数值；全部为 0 时两种单位等价，可展示 0%。若正值都不超过 1 且无可靠说明，单位仍有歧义，停止转化率比较和建议。
7. 活动点击加权转化率 = `Σ(clicks_i × cvr_i) / Σclicks_i`，仅对点击量大于 0 且 CVR 有效的行计算。若任何正点击行 CVR 缺失，活动转化率标记不完整，不展示为 0%。零点击活动的加权转化率为“不适用”。
8. 货币符号仅在站点货币可以可靠确定时显示；否则标为“站点货币”，不得统一写美元。

## 建议判定

默认有效样本门槛为每活动每搜索词 20 点击。这只是筛选门槛，不代表统计显著。建议必须写明点击量、花费、加权转化率和理由。计算或活动身份不完整时先标“数据待核对”，不做倾斜、暂停或否定。

- **主推并倾斜**：同一搜索词至少有两个身份明确、数据完整、各达 20 点击的活动；某活动的正转化率严格高于其他合格活动，才作为相对主推候选。并列、差距无法解释或仅一个活动时不设主推。用“候选”表达，避免宣称因果或显著性。
- **保留测试**：正转化但点击不足 20、零转化且点击不足 20，或只有一个活动且仍有转化时，继续观察；不能据此声称跨活动优胜。零点击活动只展示“样本不足”。
- **降低出价／限流**：只在可比较且活动样本均达 20 点击、数据完整、某活动转化率低于主推候选时提出，并提醒人工核对。零转化但点击不足 20 的活动归入保留测试，不据此限流。不得给出未经数据支持的具体出价幅度。
- **暂停／活动级否定候选**：零转化且该活动该词点击达到 20，数据完整，且已核对报告更新与归因成熟。归因是否成熟无法确认时先列为“数据待核对／暂缓执行”。只能针对本活动提出候选；若同词在别的活动有转化，不得建议全局否定。不能直接执行广告变更。

如无可比较的两个活动，页面明确写“当前无法比较同词跨活动转化差异”，但仍可展示该词的单活动观察建议。花费高低单独不能证明转化优劣。
