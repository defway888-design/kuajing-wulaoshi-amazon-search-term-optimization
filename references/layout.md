# 跨境吴老师搜索词看板固定版式

## 唯一页面实现

`assets/dashboard_template.html` 是已确认模拟看板的页面母版，`scripts/render_dashboard.py` 是筛选页和正式页的唯一渲染入口。模板保留模拟版的标题、配色、筛选布局、图表和提示框交互，新增的筛选确认控件只在第一阶段显示；渲染器只替换 Logo 与经过验证的数据插槽。不得依照本说明另写页面、改用其他组件库或重新绘制图表。模板指纹由渲染器核验，指纹不符立即停止。两阶段文件均须通过各自的 `--check` 与同一输入逐字节核对。

“一致”指在**相同浏览器版本、视口尺寸、缩放比例和可用字体**下，页面由同一 HTML/CSS/JS 母版渲染，结构、组件位置、配色、字号、间距和交互实现一致。真实搜索词数量、名称长度、指标数值、图表条数、日期、状态文案和离线真实数据标识按本次数据变化。跨浏览器、系统字体、系统缩放和设备像素比会影响像素栅格，不能承诺逐像素一致；不能以此为由自行改变母版。

## 固定页面结构

1. 顶部仅保留“跨境吴老师AMAZON广告搜索词优化看板”标题、右侧内嵌真实 Logo 和数据状态标识。Logo 在所有断点均为 60px 高。标题下无副标题；无“数据说明”板块。
2. 一个筛选面板，顺序为统计日期、站点、国家、店铺、广告组合名称、广告活动名称、广告组名称、客户搜索词，含重置按钮和筛选状态行。关键词是原生单选下拉框。筛选选项取当前数据，切换后即刻更新可选关键词。
3. 筛选页初次只显示标题、筛选面板、确认按钮和页脚；活动图与建议面板隐藏。确认按钮导出选择 JSON，页面同时显示可手动复制的内容。筛选页不得进行活动花费／CVR 分析。用户返回选择 JSON 后才能生成正式页。
4. 正式页以用户选择为初始视图，仍可改筛选；一个明细面板同时容纳所选词的活动图与优化建议。图表按 Profile 与币种分面，每个数据完整的活动一个花费柱和一个点击加权 CVR 节点，同活动广告组聚合。鼠标悬停、键盘聚焦均显示完整数值提示。多币种不共享金额轴。
5. 页脚标明数据来源。正式页不得增加模拟版没有的解释卡片、独立建议面板、活动组柱或横向关键词墙。

以上容器、断点和各控件样式直接以模板为准，本文件不另行定义可漂移的 CSS 数值。

## 验收

- 分别用 `--phase selection --check`、`--phase final --selection ... --check` 证明两份输出与母版和本次数据完全一致；核对输出只内嵌数据与 Logo，不依赖 CDN、在线图片和本机文件。
- 检查筛选页只有维度和词点击量，没有花费／CVR 数据或活动建议；确认后导出的选择文件包含本次数据指纹、八项条件，不含源内部 ID。修改数据或旧选择文件必须拒绝生成正式页。
- 检查四窗口切换、七项条件交集与关键词单选、重置、零结果、长名称、同名活动、No Portfolio、跨币种、提示框的鼠标和键盘交互。
- 在可用的相同浏览器条件下目视检查桌面与窄屏，不得出现串行、错列、文字遮挡、字体对齐异常或页面整体横向滚动。若执行平台不能目视渲染，只能报告结构与脚本验证结果，不得声称完成视觉 QA。
