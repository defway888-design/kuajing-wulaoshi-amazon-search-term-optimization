# 跨境吴老师搜索词看板固定版式

## 唯一页面实现

`assets/dashboard_template.html` 是已确认模拟看板的正式页面母版，`scripts/render_dashboard.py` 是唯一渲染入口。第一阶段只在当前对话收集筛选条件，不生成页面。正式模板保留模拟版的标题、配色、筛选布局、图表和提示框交互；渲染器只替换 Logo 与经过验证的数据插槽。不得依照本说明另写页面、改用其他组件库或重新绘制图表。模板指纹由渲染器核验，指纹不符立即停止；正式文件须通过 `--check` 与输入逐字节核对。

“一致”指在**相同浏览器版本、视口尺寸、缩放比例和可用字体**下，页面由同一 HTML/CSS/JS 母版渲染，结构、组件位置、配色、字号、间距和交互实现一致。真实搜索词数量、名称长度、指标数值、图表条数、日期和状态文案按本次数据变化。跨浏览器、系统字体、系统缩放和设备像素比会影响像素栅格，不能承诺逐像素一致；不能以此为由自行改变母版。

## 固定页面结构

1. 顶部仅保留“跨境吴老师AMAZON广告搜索词优化看板”标题和右侧内嵌真实 Logo。Logo 在所有断点均为 60px 高。标题下无副标题；无“数据说明”板块或数据状态徽标。
2. 一个筛选面板，顺序为统计日期、国家、店铺、广告组合名称、广告活动名称、广告组名称、客户搜索词，含重置按钮和筛选状态行。没有独立的站点筛选卡片；国家控件内部映射站点代码。关键词是原生单选下拉框。筛选选项取当前数据，切换后即刻更新可选关键词。
3. 正式页以用户在当前对话提交的日期、国家和店铺为初始视图，七项筛选在本次已读取范围内可切换；一个明细面板同时容纳所选词的活动图与优化建议。图表按 Profile 与币种分面，每个数据完整的活动一个花费柱和一个点击加权 CVR 节点，同活动广告组聚合。图表在宽屏时将活动位置铺满卡片可用宽度，活动多时保持横向滚动，并随视口变化重排；鼠标悬停、键盘聚焦均显示完整数值提示。多币种不共享金额轴。
4. 页脚标明数据来源。正式页不得增加模拟版没有的解释卡片、独立建议面板、活动组柱或横向关键词墙。

以上容器、断点和各控件样式直接以模板为准，本文件不另行定义可漂移的 CSS 数值。

## 验收

- 用 `--check` 证明正式输出与母版及输入完全一致；文件不依赖 CDN、在线图片、本机服务或其他文件。
- 检查第一阶段三项筛选直接出现在运行 Skill 的当前对话；用户提交之前不调用报告工具，也不创建筛选 HTML 或打开新页面。
- 检查正式页在本次已获取范围内的七项筛选、关键词单选、重置、零结果、长名称、同名活动、No Portfolio、跨币种、提示框的鼠标和键盘交互，以及宽屏图表占满可用宽度。
- 在可用的相同浏览器条件下目视检查桌面与窄屏，不得出现串行、错列、文字遮挡、字体对齐异常或页面整体横向滚动。若执行平台不能目视渲染，只能报告结构与脚本验证结果，不得声称完成视觉 QA。
