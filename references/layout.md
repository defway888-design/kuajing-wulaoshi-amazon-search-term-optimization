# 跨境吴老师搜索词看板固定版式

## 唯一页面实现

`assets/dashboard_template.html` 是已确认模拟看板的页面母版，`scripts/render_dashboard.py` 是唯一正式渲染入口。模板内保留模拟版的 CSS、DOM 容器、筛选布局、图表和提示框交互；渲染器只替换 Logo 与经过验证的数据插槽。不得依照本说明另写页面、改用其他组件库或重新绘制图表。模板指纹由渲染器核验，指纹不符立即停止。正式文件须通过 `--check` 与同一输入逐字节核对。

“一致”指在**相同浏览器版本、视口尺寸、缩放比例和可用字体**下，页面由同一 HTML/CSS/JS 母版渲染，结构、组件位置、配色、字号、间距和交互实现一致。真实搜索词数量、名称长度、指标数值、图表条数、日期、状态文案和离线真实数据标识按本次数据变化。跨浏览器、系统字体、系统缩放和设备像素比会影响像素栅格，不能承诺逐像素一致；不能以此为由自行改变母版。

## 固定页面结构

1. 顶部仅保留“跨境吴老师AMAZON广告搜索词优化看板”标题、右侧内嵌真实 Logo 和数据状态标识。Logo 在所有断点均为 60px 高。标题下无副标题；无“数据说明”板块。
2. 一个筛选面板，顺序为统计日期、站点、国家、店铺、广告组合名称、广告活动名称、广告组名称、客户搜索词，含重置按钮和筛选状态行。关键词是原生单选下拉框。筛选选项取当前数据，切换后即刻更新一个词的看板。
3. 一个明细面板，同时容纳所选词的活动图与优化建议。图表按 Profile 与币种分面，每个活动一个花费柱和一个点击加权 CVR 节点，同活动广告组聚合。鼠标悬停、键盘聚焦均显示完整数值提示。多币种不共享金额轴。
4. 页脚标明数据来源与必要的归因提醒。页面不得增加模拟版没有的解释卡片、独立建议面板、活动组柱或横向关键词墙。

以上容器、断点和各控件样式直接以模板为准，本文件不另行定义可漂移的 CSS 数值。

## 验收

- 用 `render_dashboard.py --check` 证明输出与母版和本次数据完全一致；核对输出只内嵌数据与 Logo，不依赖 CDN、在线图片和本机文件。
- 检查四窗口切换、七项条件交集与关键词单选、重置、零结果、长名称、同名活动、No Portfolio、跨币种、提示框的鼠标和键盘交互。
- 在可用的相同浏览器条件下目视检查桌面与窄屏，不得出现串行、错列、文字遮挡、字体对齐异常或页面整体横向滚动。若执行平台不能目视渲染，只能报告结构与脚本验证结果，不得声称完成视觉 QA。
