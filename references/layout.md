# 固定看板版式

这份规格根据用户提供的脱敏 HTML 参考页面抽取，只包含结构和样式，不包含任何示例搜索词、活动或指标。运行时不得依赖该用户电脑上的原始 HTML 路径。

## 页面结构

1. 页面顶部左侧只有一级标题：`跨境吴老师AMAZON广告搜索词优化看板`。浏览器标签同名。标题下不显示副标题、店铺与日期说明、指标口径、样本阈值或活动数量。右侧保留带“客户搜索词”标签的 Top10 选择框。
2. 居中的白色主面板顶部：左侧“当前筛选：<搜索词>”，右侧两项图例：蓝色花费、红色点击加权转化率。
3. 主面板中部：蓝柱（花费）＋红线及圆点（转化率）组合图，左右两条纵轴各自显示单位，横轴为广告活动。只有一个活动时保留红点，不伪造折线或第二个活动。
4. 图表下方：“当前关键词优化建议”，按实际出现的“主推并倾斜、保留测试、降低出价／限流、暂停／活动级否定候选、数据待核对”分组；每组活动名称及理由独立成行。
5. 存在暂停或否定候选时，末尾显示浅红色归因复核提醒。无候选则隐藏。

不要增加侧边栏、KPI 卡片、表格主视图、订单／销售／ACOS／ROAS 组件或参考页面以外的业务模块。报告日期、店铺等审计上下文可放入交付说明或不干扰标题的可展开详情，不得再出现标题下第二行。

## 视觉与对齐

- 页面最大宽约 1220px，居中；背景 `#F6F8FC`；主面板白色，边框 `#E6ECF5`，圆角 14px；页面和主面板内边距约 24px。
- 标题 `#1F365C`、26px；正文 `#52657D`、14px；辅助文字 `#7B8BA0`。字体用 Arial、Microsoft YaHei 和系统无衬线回退，`letter-spacing:0`。
- 花费柱 `#3478D5`；转化率线 `#DB4B35`。建议标签：主推绿、测试蓝、限流橙、暂停红、待核灰。
- 使用 Grid/Flex 和 `box-sizing:border-box`；标题列用 `minmax(0,1fr)`，控件列约 280–420px，选择框宽度 100%。不靠空格或固定字符数排齐。
- 图表容器独立横向滚动，按活动数扩展宽度，每活动至少约 120px；页面本身不得横向溢出。长活动名可截短并倾斜，但悬停必须看到全名。文字容器要安全换行，图例可换行，数值与单位对齐。
- 视口不宽于 760px 时，标题与选择器上下排列，主面板内边距约 16px。图表仍只在自身容器滚动。

## 交互与验收

选择框只列真实存在的最多 10 个搜索词，切换时同步更新当前筛选、图表、分组建议和提醒。使用 `textContent` 或等效转义插入用户／MCP 文本，防止搜索词或活动名破坏 HTML。页面应为离线单文件，不依赖 CDN。

交付前检查常见桌面和手机宽度，并切换全部搜索词，重点检查最长名称与最多活动的情况：不得串行、错列、文字覆盖、字体不齐、坐标碰撞或页面整体横向滚动。若环境不允许渲染预览，如实说明未完成目视验收。
